# Sky data credits

All files in this folder are generated by `scripts/build-sky-data.mjs` and
`scripts/sky-data/prepare-moon.py` from the sources below.

| File | Source | License |
| --- | --- | --- |
| `stars.bin` | [HYG Stellar Database v4.4](https://codeberg.org/astronexus/hyg) by David Nash / astronexus (Hipparcos, Yale BSC, Gliese) | CC BY-SA 4.0 |
| `constellations.json` | [Stellarium "Modern" sky culture](https://github.com/Stellarium/stellarium/tree/master/skycultures/modern): constellation lines, art anchors, star names | CC BY-SA 4.0 (text and data) |
| `art/*.png` | Constellation illustrations by [Johan Meuris](https://johanmeuris.eu/work/stellarium-constellation-art/) for Stellarium | Free Art License 1.3 |
| `milkyway.jpg` | [NASA/Goddard SVS, Deep Star Maps 2020](https://svs.gsfc.nasa.gov/4851) (Milky Way layer). Gaia DR2: ESA/Gaia/DPAC | NASA media, public domain |
| `horizon.json` | Ridge silhouettes around IIT Mandi computed from [Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) (SRTM), accessed 2026-10-01 | Open data, attribution required |
| `moon.jpg` | ["FullMoon2010.jpg"](https://commons.wikimedia.org/wiki/File:FullMoon2010.jpg) by Gregory H. Revera | CC BY-SA 3.0 |

Sun, Moon and planet positions are computed at runtime with
[Astronomy Engine](https://github.com/cosinekitty/astronomy) (MIT).
